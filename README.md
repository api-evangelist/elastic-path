Elastic Path is a headless commerce platform providing REST and GraphQL APIs for managing catalogs, products, price books, promotions, carts, orders, subscriptions, payments, and customer accounts in composable commerce architectures. It is designed for B2B, D2C, and multi-brand enterprise retailers building API-first, microservices-based shopping experiences.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/elastic-path/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/elastic-path/refs/heads/main/apis.yml)

## APIs

### Elastic Path Commerce Cloud API

REST API for the full Elastic Path Commerce Cloud platform, covering accounts, addresses, application keys, catalogs, products, price books, promotions, carts, checkout, orders, payments, subscriptions, inventory, flows, integrations, files, currencies, and single sign-on.

- **Human URL:** [https://developer.elasticpath.com/api](https://developer.elasticpath.com/api)
- **Base URL:** `https://useast.api.elasticpath.com`

### Elastic Path GraphQL API

GraphQL abstraction over a subset of the Elastic Path Commerce Cloud APIs, providing a flexible query interface optimized for shopper-facing experiences including product browsing and catalog queries.

- **Human URL:** [https://www.elasticpath.com/technologies/graphql-ecommerce](https://www.elasticpath.com/technologies/graphql-ecommerce)
